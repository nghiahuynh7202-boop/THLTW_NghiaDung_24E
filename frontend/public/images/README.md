# Thư mục lưu trữ hình ảnh & logo (Frontend Assets)

Bạn có thể thả các file hình ảnh, logo của bạn vào các thư mục tương ứng dưới đây:

1. `public/images/logo/`
   - `logo.png` (hoặc `logo.svg`): Logo chính cho Header
   - `logo-footer.png`: Logo cho Footer
   - `bo-cong-thuong.png`: Logo chứng nhận Đã Thông Báo Bộ Công Thương

2. `public/images/qr/`
   - `qr-code.png`: Ảnh QR Scan Me tải app / liên hệ dưới Footer

3. `public/images/banners/`
   - Banners quảng cáo, slider trang chủ

4. `public/images/products/`
   - Ảnh sản phẩm hoa tươi, giỏ hoa, cây cảnh

5. `public/images/icons/`
   - Các icon dịch vụ, thương hiệu phụ (Điện hoa, Hoa sáp, Cây xanh...)
